about toko

a cobalt.tools inspired downloader

how its put together

this is for nerds so baibai
  • each source lives in its own extractor file exporting match(url) and extract(url)
  • a queue manager runs up to four extractions concurrently and keeps an in-memory job store
  • the api exposes POST /api/batch to submit urls and GET /api/batch/:id to poll status

known gaps in this beta

  • only youtube, tiktok & insta is implemented right now, other sources are stubbed by the registry pattern
  • the job store is in-memory, a restart wipes the queue
